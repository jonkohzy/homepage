# custom new tab page :D

A personal start page with a cat GIF, a dark theme, and 16 shortcuts for work, school, development, and downtime. Built with plain HTML and CSS, using Fira Code and a blinking terminal-style prompt.

[Open the homepage](https://jonkohzy.github.io/homepage/)

## Preview locally

Open `index.html` in a browser. No installation or build step is needed. An internet connection is needed to load Fira Code from Google Fonts and open the linked sites.

## Customize

- Edit `index.html` to change the categories, shortcut labels, or destinations.
- Edit `style.css` to change the colors, layout, typography, or cursor animation.
- Replace `cat.gif` to change the illustration and `smiley.png` to change the favicon.
- Keep the shortcut table above in sync when updating the page.
